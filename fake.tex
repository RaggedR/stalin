\section*{What has to be faked}

A container is a pair $(P, R)$ with $P : \mathrm{Type}$ and
$R : P \to \mathrm{Type}$, and an inhabitant of the interface is a
\emph{dependent} function $(p : P) \to R\,p$ --- the type of the result depends
on the \emph{value} of the argument. The combinators of \S5 then build new
containers out of old ones, and the sequential one, $\lhd$, has for its shape a
$\Sigma$-type:
\[
  (s : \mathrm{Shape}\,A) \mathbin{**} (\mathrm{Pos}_A\,s \to \mathrm{Shape}\,B)
\]

\noindent TypeScript has none of this. No dependent function types, no
$\Sigma$-types, no $\Pi$-types. It also has no way to make a network hop
type-safe, because the wire carries JSON and JSON has no notion of a type.

So four things are faked, and this note is an account of each and of exactly
where the fake leaks. The short version: the type-level fakery is sound over
finite indices and costs ten casts, all in one library file; the
\emph{runtime} fakery is not sound at all, and that is unavoidable.

\section{Fake 1 --- the container as its graph}

$R$ cannot be a function from values to types. But a container can be
presented not as the pair $(\mathrm{Shape}, \mathrm{Pos})$ but as its
\textbf{graph}: the union of its fibres. Over a \emph{finite} index this is an
equality, not an approximation:
\[
  \Sigma\,(s : S).\,B\,s \;=\; \bigcup_{s \in S}\ \{s\} \times B\,s
\]

\noindent and every container here has a finite shape type, because a shape
type is a tagged union. TypeScript's conditional types distribute over unions,
so the dependent lookup becomes a conditional type:

\begin{lstlisting}
interface Fib<S, P> { readonly shape: S; readonly pos: P }
type Cont = Fib<unknown, unknown>;

type Shape<C extends Cont> = C extends Fib<infer S, unknown> ? S : never;

type PosAt<C extends Cont, S> =
  C extends Fib<infer S1, infer P> ? (S extends S1 ? P : never) : never;
\end{lstlisting}

\noindent A container is then written as a union of \texttt{Fib}s, one per
prompt:

\begin{lstlisting}
type AgricultureC =
  | Fib<{tag:"Harvest"; workforce: Workforce; year: number}, HarvestReport>
  | Fib<{tag:"Winter";  ruralRations: Grain;  year: number}, WinterReport>
  | Fib<{tag:"Census"}, CensusReturn>;
\end{lstlisting}

\fake{Where this is honest.} \texttt{Fib} is \emph{never constructed}. There is
no value of that type anywhere in the program; it is a type-level record --- the
object language of $\mathrm{Fam}(\mathrm{Set}^{\mathrm{op}})$ --- and exists
only to be taken apart by \texttt{infer}. Nothing is being simulated at
runtime. The union genuinely \emph{is} the graph of $R$.

\subsection*{Two traps, both silent}

\fake{The direction of the fibre test.} The obvious spelling of \texttt{PosAt}
is \texttt{Extract<C, Fib<S, unknown>>}, which keeps the fibres assignable
\emph{to} the query. But a shape you actually hold is usually \emph{narrower}
than its fibre's declared shape --- a literal tag, a specific type. What is
wanted is the fibre this shape lies in: \texttt{S extends S1}, not the reverse.
Written the wrong way round, every position silently becomes \texttt{never}, and
nothing complains anywhere near the mistake.

\fake{Conditional types are not inference sites.} If \texttt{C} occurs only
inside \texttt{Shape<C>} and \texttt{PosAt<C, S>}, TypeScript cannot infer it.
\texttt{seqC(a, b)} then quietly infers \texttt{A = Cont}, every downstream
position becomes \texttt{unknown}, and again there is no error where the error
is. The remedy is a phantom field that never holds anything:

\begin{lstlisting}
interface Runner<C extends Cont> {
  readonly fibres?: C;   // never assigned; exists so C is inferable
  readonly label: string;
  run<S extends Shape<C>>(shape: S, depth: number): Promise<PosAt<C, S>>;
}
\end{lstlisting}

\section{Fake 2 --- the dependent function as a generic \texttt{async} method}

$(p : P) \to R\,p$ becomes the \texttt{run} signature above. The dependency is
real but it is carried at the level of \emph{types}, not values: \texttt{S} is
inferred from the argument, and the return type \texttt{PosAt<C, S>} is
computed from \texttt{S}. Prompt with a \texttt{Harvest} and you are handed a
\texttt{HarvestReport}; prompt with a \texttt{Census} and you are handed a
\texttt{CensusReturn}; the two are not interchangeable, and no call site casts.

\fake{What \texttt{async} adds, and what it does not.} \texttt{Promise<...>}
is bookkeeping for the fact that the answer arrives over a socket. It is not
part of the container. A container says nothing about waiting --- Ghani's point
in \S3 is that what makes a program event-driven is the prompt-indexed response
type, not the event loop. Strip the \texttt{await} away and the container is
what remains; the \texttt{Promise} is the fake, not the structure.

\section{Fake 3 --- the delegate leg as a CLI tool}

A morphism $(P,R) \to (Q,T)$ is a pair: $u : P \to Q$ sending control
\emph{down}, and $f$ bringing data \emph{up}. Here $u$ is not a function call.
It is a process:

\begin{lstlisting}
delegate.ts <port> <json-prompt> <depth>      # stdout is the reply, as JSON
\end{lstlisting}

\noindent That file knows nothing about any container. It takes a port, a JSON
prompt and a depth, and carries the text across. The ignorance is the point:
$u$ is a map of \emph{shapes}, and shapes are exactly what survives a wire.

\fake{This one is arguably not a fake at all.} A function call pretending to be
a boundary is the usual way to model this; here the boundary is real. Control
genuinely leaves the process. The cost is about a fifth of a second per hop,
and since Gosplan fans out to four commissariats, one ten-turn game is roughly
forty spawns.

\fake{And the fake bites where the compiler cannot see.} \texttt{wire.ts}
locates that tool with

\begin{lstlisting}
new URL("./delegate.ts", import.meta.url)   // resolved at run time, never checked
\end{lstlisting}

\noindent Every file once typechecked cleanly and the first playthrough died
at once --- \texttt{delegate to :8804 exited 1} --- because that file had not
been copied when the library was vendored. \textbf{Types hold within a process.
The moment a boundary is a filesystem path or a socket, only running it tells
you the truth.}

\section{Fake 4 --- the combinators as values}

Each combinator is a function returning a \texttt{Runner} for the composite,
together with an \emph{introduction rule} for its shapes. The introduction
rules are where the typing is won: each is generic in the fibre, so the checker
knows which fibre you are in.

\begin{lstlisting}
tensorC(a, b).both(leftShape, rightShape)    // (x)  ask both, both must answer
seqC(a, b).step(first, next)                 //  <|  the dependent pair
productC(a, b, choose).offer(aShape, bShape) //  x   ask both, one answers
sumC(a, b).left(shape) | .right(shape)       //  +   route
\end{lstlisting}

\noindent The tensor's body is three lines, and the middle one is the whole
definition rather than an optimisation:

\begin{lstlisting}
const [left, right] = await Promise.all([a.run(s.left, depth), b.run(s.right, depth)]);
return { left, right } as PosAt<TensorC<A, B>, S>;
\end{lstlisting}

\noindent The sequential composition is the interesting one, because its shape
carries a \emph{function}:

\begin{lstlisting}
step<SA extends Shape<A>, SB extends Shape<B>>(
  first: SA,
  next: (r: PosAt<A, SA>) => SB,      // SA is inferred from `first`, so `next`
): {first: SA; next: (r: PosAt<A, SA>) => SB}   // is typed at THAT fibre alone
\end{lstlisting}

\begin{lstlisting}
const first  = await a.run(s.first, depth);
const second = await b.run(s.next(first), depth);   // <-- this application IS  <|
\end{lstlisting}

\noindent That is the $\Sigma$-type, faked: not a pair of prompts, but a prompt
together with a function from its replies to the next prompt, and \texttt{next}
contextually typed at the fibre you actually gave.

\fake{The known cost.} \texttt{next} must be \emph{pure} --- it is a function
of the position and returns only a shape. When the game needs a decision made
inside \texttt{next} to be visible afterwards, it is captured in a closure
variable and read back after the run. That works, and it is flagged in the
source, but it is a concession: the honest version would carry the decision in
the composite shape.

\section{Where the fake leaks}

\subsection*{Ten casts, all in one file}

Every \texttt{run} body must destructure a shape it knows only through a
conditional type, and re-assert the result. That is two casts per combinator:

\begin{center}
\footnotesize
\begin{tabular}{@{}lrl@{}}
\toprule
site & casts & what is asserted \\
\midrule
\texttt{leaf}     & 2 & the shape has a \texttt{tag}; the decoded reply is the position \\
\texttt{sumC}     & 2 & the shape is a tagged side; the reply is the position \\
\texttt{tensorC}  & 2 & the shape is a pair; the pair of replies is the position \\
\texttt{productC} & 2 & the shape is a pair; \texttt{\{side, value\}} is the position \\
\texttt{seqC}     & 2 & the shape is \texttt{\{first, next\}}; \texttt{\{first, second\}} is the position \\
\midrule
\textbf{total}    & \textbf{10} & all inside \texttt{lib/algebra.ts}, 260 lines \\
\bottomrule
\end{tabular}
\end{center}

\noindent None of them is in the game. The game body has casts, but they are of
a different kind entirely --- \texttt{as const} on literals, and narrowing
strings that a validator has already checked. \textbf{No call site in
\texttt{stalin} ever asserts the type of a container position.} The fakery is
confined, which is the most that can be claimed for it, and rather more than
nothing.

\subsection*{The JSON boundary, which is not faked but simply unsound}

JSON has six kinds of value and no notion of types. When
\texttt{\{"tag":"Harvest", \ldots\}} arrives, the server has not received a
\texttt{Harvest}; it has received a stranger's assertion that this is one.

Worse, a wrong assertion usually does not crash. In JavaScript a missing
property reads as \texttt{undefined} rather than raising, so a handler reading
a field that was never sent returns normally, with HTTP 200, carrying a
well-formed reply of exactly the type the container demands and a value that
means nothing. A crash would have been the better outcome: loud, immediate, and
it would name the line.

So both directions are validated rather than cast. Prompts: each server's
\texttt{parse} takes \texttt{unknown} and returns the prompt type \emph{or
null}, and 56 field checks across the five servers go through what the tag
claims. Replies: each leaf carries per-shape decoders keyed by tag,

\begin{lstlisting}
type Decoders<C extends Cont> = {
  [K in TagOf<Shape<C>>]: (u: unknown) => PosAt<C, Extract<Shape<C>, {tag:K}>> | null;
};
\end{lstlisting}

\noindent which is a mapped type over the tags, so \textbf{the compiler will
not let you forget a fibre}. Deleting one decoder while its fibre still existed
was a compile error --- the fibre and its handler are one fact stated twice, and
the checker insists they agree.

\subsection*{The leak the type system cannot even see}

\texttt{seqC(a, b)} is a perfectly good \emph{value} whether or not anybody
ever applies it. The checker verifies that a composite is well-formed; it never
verifies that it is \emph{reached}. One such composite sat declared, exported
in the flow label, and silently never fired through an entire release --- twice,
in fact, and both times it was found by writing documentation rather than by
compiling.

\section*{What is real}

\begin{itemize}\itemsep2pt
\item The dependent lookup. Over a finite index the graph presentation is an
      equality, and the reply type genuinely follows from the prompt.
\item The game's own rules as fibres. Which export decisions exist is a
      function of the harvest grade, so shipping the maximum out of a failed
      harvest is a \emph{type error} rather than a validation message.
\item The boundary. Control really does leave the process.
\item The exhaustiveness of the decoders.
\end{itemize}

\section*{What is not}

\begin{itemize}\itemsep2pt
\item Ten casts inside the combinators, unavoidable given conditional types.
\item Everything about the wire. The type guarantees the \emph{shape} of a
      reply and nothing whatever about its truth --- which, in a game where every
      commissariat inflates its dispatches, turned out to be the subject rather
      than a limitation.
\end{itemize}
